KBO 프로야구 일별 승부 예측 분석

KBO 리그 경기 데이터를 실시간으로 수집하고, 몬테카를로 시뮬레이션을 통해 각 경기의 승패 확률을 예측하는 웹 애플리케이션입니다.

블로그 주소: https://namjinwoo.github.io/kbo/

기술 스택

구분 사용 기술
백엔드 Python 3.9, Flask, SQLAlchemy
데이터베이스 SQLite (data/kbo.db)
시뮬레이션 NumPy (포아송 분포)
AI 분석 Anthropic Claude API (claude-sonnet-4-6, 프롬프트 캐싱 적용)
데이터 수집 requests + 정규표현식 HTML 파싱
차트 Chart.js (득점 분포 시각화, 삼성 득실점 차트)
자동화 GitHub Actions (매일 오전 10시 KST 자동 실행)

데이터 출처

1. statiz.co.kr

수집 항목 상세
팀 순위표 순위, 경기 수, 승/무/패, 승률, 득점/실점
예정 경기 선발 투수 이름, 시즌 스탯 (ERA, WHIP, WAR, 탈삼진, 볼넷 등)
선발 H2H 해당 투수의 상대 팀 타선 통산 ERA·OOPS·WHIP
위험 타자 상대 선발투수를 상대로 강한 타자 목록 (OPS 기준)
팀 전력 비교 팀 타율, 팀 OPS, 팀 ERA, 선발/불펜 WAR, 최근 맞대결
완료 경기 점수, 승리·패전·세이브·홀드 투수
리그 리더보드 타격/투구 카테고리별 리그 상위 3인 (삼성 탭 활용)

2. koreabaseball.com (KBO 공식)

수집 항목 상세
선발 투수 이름 예정 경기 원정·홈 선발 투수명 (GetKboGameList API)
최근 10경기 성적 "6승0무4패" 형식
연속 기록 "3승" / "7패" 형식
홈/원정 전적 각각 "승-무-패" 형식
박스스코어 타자·투수 전체 기록 (GetBoxScore API)
과거 날짜 경기 결과 점수, 승패투수, 구장 — 누락 날짜 자동 백필

선발 투수 미정 경고: 선발이 발표되지 않은 경기는 예측 카드에 ⚠ 선발 미정 — 신뢰도 낮음 뱃지가 표시됩니다.

자동화 (GitHub Actions)

매일 오전 10시 KST (UTC 01:00) GitHub Actions가 자동으로 실행됩니다.

GitHub Actions (ubuntu-latest)
  └─ kbo_predict 리포 체크아웃 (data/kbo.db 포함)
       └─ 스크래핑: 순위, 예정 경기, 최근 완료 경기
            └─ 누락 날짜 백필: 최근 30일 중 DB에 없는 날짜를 KBO API로 채움
                 └─ build_blog.py 실행 → GitHub Pages push
                      └─ 업데이트된 data/kbo.db → kbo_predict 리포 commit & push

수동 실행: GitHub Actions 탭 → Daily KBO Update → Run workflow

DB 구조

data/kbo.db  (git 추적 — 매일 자동 commit)

TeamStat    — 팀 순위/스탯 (스크래핑마다 이전 전체 삭제 후 최신 10행만 유지)
TodayGame   — 예정 경기 + 선발 투수 + 통계 JSON (오늘 이전 날짜 자동 삭제)
RecentGame  — 완료된 경기 결과 (30일 rolling window 자동 유지)
Prediction  — 사용자 저장 예측 + 실제 결과 대조

DB 용량 관리

테이블 보관 정책 안정 행 수
TeamStat 최신 스크래핑 1회분만 유지 10행
TodayGame 오늘 이후 날짜만 유지 5~10행
RecentGame 최근 30일 rolling window ~150행

→ DB 크기 약 150KB로 안정화, git 연간 누적 ~50MB 이하

RecentGame 자동 추가 필드

필드 내용
predicted_winner 시뮬레이션 예측 승팀
sim_confidence 예측 확신도 (%) — shrinkage 적용 후 값
sim_json 예측 시점 핵심 시뮬레이션 데이터 (factors, λ, ERA, 상성 등)
result_analysis 예측 vs 실제 자동 분석 텍스트 (markdown)

시뮬레이션 방식

개요

포아송 분포 기반 몬테카를로 시뮬레이션 10,000회를 실행하여 각 팀의 기대 득점(λ)을 추정하고, 득점 분포에서 승패 확률을 도출합니다.

numpy.random.poisson(λ_away, 10_000)  →  원정 팀 득점 분포
numpy.random.poisson(λ_home, 10_000)  →  홈 팀 득점 분포

away_wins = Σ(원정득점 > 홈득점) + 동점 × 0.5
home_wins = Σ(홈득점 > 원정득점) + 동점 × 0.5

λ (기대 득점) 계산 방법

각 팀의 λ는 블렌딩된 경기당 득점(RPG)을 기준으로 여러 보정 계수를 곱해 산출합니다.

λ_away = RPG_away(블렌딩) × ERA계수 × K-BB/9계수 × 피로도계수
       × 최근흐름 × 원정전적계수 × 위험타자계수 × 맞대결계수
       × 파크팩터 × 홈불펜복합계수

λ_home = RPG_home(블렌딩) × ERA계수 × K-BB/9계수 × 피로도계수
       × 최근흐름 × 홈전적계수 × 위험타자계수 × 맞대결계수
       × 홈어드밴티지(1.01) × 파크팩터 × 원정불펜복합계수

λ는 최소 2.5, 최대 10.0으로 클램핑됩니다.

각 계수 상세

0. RPG 블렌딩 (시즌 + 최근 폼)

RPG_블렌딩 = 시즌_RPG × 0.80 + 최근7경기_평균득점 × 0.20
  • 최근 경기 데이터가 4경기 미만이면 시즌 RPG만 사용 (이상값 방지)
  • 최근 RPG는 리그평균의 ±40% 이내로 클램핑 (단일 폭발 게임 영향 억제)

1. ERA 계수 (선발 투수 지배력)

ERA계수 = ERA / 리그평균ERA(4.50)
범위: [0.55, 1.75] 클램핑

시즌 ERA + H2H ERA 블렌딩:

H2H_가중치 = 0.35 (5경기 이상) / 0.25 (5경기 미만)
ERA계수(최종) = 시즌ERA계수 × (1 - H2H_가중치) + H2H_ERA계수 × H2H_가중치

2. K-BB/9 폼 계수 (투수 구위·제구 종합)

K-BB/9계수 = 1.0 - (K-BB/9 - 4.5) / 4.5 × 0.15
범위: [0.93, 1.07] 클램핑

3. 피로도 계수 (최근 등판 간격)

2일 이내 등판 → 피로도계수 = 1.10 (상대 득점 10% 증가)
3일 이내 등판 → 피로도계수 = 1.05 (상대 득점 5% 증가)
4일 이상      → 피로도계수 = 1.00 (정상)

4. 최근 흐름 (연속 기록)

흐름계수 = 1.0 + min(|연속수|, 5) × 0.015 × 방향(+1/-1)

5. 홈/원정 전적 계수

홈전적계수 = 홈승률 / 0.500
원정전적계수 = 원정승률 / 0.500
범위: [0.75, 1.20] 클램핑

6. 위험 타자 OPS 계수

위험타자계수 = 1.0 + (평균OPS / 리그평균OPS(0.750) - 1.0) × 0.25
범위: [0.90, 1.15] 클램핑

7. 최근 맞대결 계수

맞대결계수 = (맞대결승수 / 총맞대결수) / 0.5
범위: [0.92, 1.08] 클램핑

8. 통산 상대팀 승률 계수 (상성)

상성계수 = 1.0 - (통산승률 - 0.5) × 0.20 × 샘플가중치
샘플가중치 = min(1.0, 통산경기수 / 15)
범위: [0.93, 1.07]

3경기 미만은 샘플 부족으로 무시.

9. 홈 어드밴티지

홈 팀 λ에 고정 계수 1.01 적용.

10. 파크팩터 (구장 특성)

홈팀 구장 파크팩터
LG / 두산 잠실 1.05
한화 대전 한화생명이글스파크 1.02
KIA 광주 챔피언스필드 1.01
롯데 부산 사직구장 1.00
삼성 대구 라이온즈파크 0.97
SSG 인천 SSG 랜더스필드 0.97
키움 서울 고척 스카이돔 0.96
NC 창원 NC파크 0.95
KT 수원 KT 위즈파크 0.93

11. 불펜 복합 계수 (WAR + 팀ERA 교차 검증)

불펜WAR계수  = 1.0 - (불펜WAR - 리그평균(3.0)) / 3.0 × 0.25   → [0.92, 1.08]
팀ERA계수    = 1.0 + (팀ERA - 4.50) / 4.50 × 0.18              → [0.93, 1.07]

불펜복합계수 = 불펜WAR계수 × 0.60 + 팀ERA계수 × 0.40

최종 승률 산출

raw승률(원정) = 시뮬레이션승률 × 0.70 + 최근10경기승률 × 0.30

# Shrinkage: 극단적 확신도를 50%로 수렴 (계수 0.75)
최종승률(원정) = 50 + (raw승률 - 50) × 0.75
최종승률(홈)   = 100 - 최종승률(원정)

예) raw 80% → 최종 62.5% / raw 60% → 최종 57.5%

/admin/scrape (POST) 데이터 수동 갱신 + 누락 날짜 자동 백필

AI 분석 (Claude API)

ANTHROPIC_API_KEY 설정 시 Claude API로 서술형 분석 생성, 미설정 시 규칙 기반 fallback 자동 적용.

프롬프트 캐싱 적용: 분석 포맷 지침을 system 블록으로 분리하고 cache_control: ephemeral을 적용하여 같은 날 여러 경기 분석 시 토큰 비용 30~50% 절감.

실행 방법

# 의존성 설치
pip install -r requirements.txt

# 환경변수 설정 (AI 분석 사용 시)
export ANTHROPIC_API_KEY=sk-ant-...

# 앱 실행
python run.py

브라우저에서 http://localhost:5000 접속 후, 홈 화면의 데이터 갱신 버튼을 눌러 최신 데이터를 수집합니다.
