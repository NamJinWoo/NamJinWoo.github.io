KBO 프로야구 일별 승부 예측 분석

KBO 리그 경기 데이터를 실시간으로 수집하고, 몬테카를로 시뮬레이션을 통해 각 경기의 승패 확률을 예측하는 웹 애플리케이션입니다.

기술 스택

구분 사용 기술
백엔드 Python 3.9, Flask, SQLAlchemy
데이터베이스 SQLite
시뮬레이션 NumPy (포아송 분포)
AI 분석 Anthropic Claude API (claude-sonnet-4-6)
데이터 수집 requests + 정규표현식 HTML 파싱

시뮬레이션 방식

개요

포아송 분포 기반 몬테카를로 시뮬레이션 10,000회를 실행하여 각 팀의 기대 득점(λ)을 추정하고, 득점 분포에서 승패 확률을 도출합니다.

numpy.random.poisson(λ_away, 10_000)  →  원정 팀 득점 분포
numpy.random.poisson(λ_home, 10_000)  →  홈 팀 득점 분포

away_wins = Σ(원정득점 > 홈득점) + 동점 × 0.5
home_wins = Σ(홈득점 > 원정득점) + 동점 × 0.5

λ (기대 득점) 계산 방법

각 팀의 λ는 시즌 평균 경기당 득점을 기준으로 여러 보정 계수를 곱해 산출합니다.

λ_away = 원정팀_RPG × ERA계수 × 최근흐름 × 원정전적계수 × 위험타자계수 × 맞대결계수
λ_home = 홈팀_RPG  × ERA계수 × 최근흐름 × 홈전적계수   × 위험타자계수 × 맞대결계수 × 홈어드밴티지(1.04)

λ는 최소 2.0, 최대 10.0으로 클램핑됩니다.

각 계수 상세

1. ERA 계수 (선발 투수 지배력)

상대 선발 투수의 ERA로 자 팀의 득점 기대값을 조정합니다.

ERA계수 = ERA / 리그평균ERA(4.50)
범위: [0.55, 1.75] 클램핑

예) 상대 선발 ERA 2.25 → 계수 0.55 (득점 45% 억제)
예) 상대 선발 ERA 6.75 → 계수 1.50 (득점 50% 증가)

시즌 ERA + H2H ERA 블렌딩:
상대전적 ERA는 샘플이 적어 과가중을 피하기 위해 아래 비율로 혼합합니다.

ERA계수(최종) = 시즌ERA계수 × 0.75 + H2H_ERA계수 × 0.25

H2H 데이터가 없을 경우 시즌 ERA만 사용합니다.

2. 최근 흐름 (연속 기록)

연승/연패 기록으로 팀의 현재 모멘텀을 반영합니다.

흐름계수 = 1.0 + min(|연속수|, 5) × 0.015 × 방향(+1/-1)

예) 5연승 → 1.075 / 5연패 → 0.925 / 연속기록 없음 → 1.0

3. 홈/원정 전적 계수

해당 시즌의 실제 홈·원정 승률을 반영합니다.

홈전적계수 = 홈승률 / 0.500
원정전적계수 = 원정승률 / 0.500
범위: [0.7, 1.3] 클램핑

4. 위험 타자 OPS 계수

상대 선발 투수를 상대로 강한 타자 상위 5명의 평균 OPS로 공격력을 보정합니다.

위험타자계수 = 1.0 + (평균OPS / 리그평균OPS(0.750) - 1.0) × 0.25
범위: [0.90, 1.15] 클램핑

5. 최근 맞대결 계수

해당 시즌 두 팀의 직접 대결 전적 비율을 반영합니다.

맞대결계수 = (맞대결승수 / 총맞대결수) / 0.5
범위: [0.92, 1.08] 클램핑

6. 홈 어드밴티지

홈 팀 λ에 고정 계수 1.04 적용 (KBO 리그 홈 팀 평균 승률 약 52~54% 기반).

최종 승률 산출

몬테카를로 결과에 최근 10경기 흐름을 30% 블렌딩합니다.

최종승률(원정) = 시뮬레이션승률 × 0.70 + 최근10경기승률 × 0.30
최종승률(홈)   = 100 - 최종승률(원정)

최근 10경기 비율은 두 팀의 최근 10경기 승수 합 대비 각 팀 승수의 비율로 산출됩니다.

분석 텍스트 생성

Claude API 사용 시 (ANTHROPIC_API_KEY 환경변수 설정)

시뮬레이션 결과, 선발 투수 스탯, 위험 타자, 팀 전력 데이터를 프롬프트로 구성하여 claude-sonnet-4-6 모델에 전달합니다. 분석 항목:

  • 핵심 포인트 3가지
  • 선발 투수 분석 (시즌 스탯 + H2H ERA/OOPS)
  • 위협 타자 분석
  • 팀 흐름 및 전력 비교 (WAR, 최근 맞대결)
  • 승부 포인트
  • 최종 예측 및 예상 스코어

API 키 미설정 시 (규칙 기반 fallback)

동일한 데이터를 기반으로 규칙 기반 텍스트를 자동 생성합니다. ERA 차이, OPS 임계값, WAR 차이 등 사전 정의된 기준으로 분석 텍스트를 조합합니다.

주요 페이지

경로 설명
/ 팀 순위표, 최근 경기 결과, 다음 예정 경기
/simulate?away=XXX&home=YYY 선택 경기 몬테카를로 시뮬레이션 실행

/predictions/<id> 예측 상세 + 분석 텍스트

/stats 예측 정확도 통계
/admin/scrape (POST) 데이터 수동 갱신

경기 상세 페이지 (/game/...)

경기가 취소되었거나 아직 결과가 없으면 박스스코어 대신 안내 메시지를 표시합니다.

시뮬레이션 한계 및 유의사항

  • 부상, 날씨, 컨디션 등 비정형 변수는 반영되지 않습니다.
  • H2H 샘플 크기가 작을 경우 해당 계수의 신뢰도가 낮습니다.
  • 선발 투수 미정 경기는 ERA 계수를 1.0(리그 평균)으로 처리합니다.
  • 본 예측은 통계적 참고 자료이며, 투자·도박 목적으로 사용하지 마십시오.
