KBO 프로야구 일별 승부 예측 분석

KBO 리그 경기 데이터를 실시간으로 수집하고, 몬테카를로 시뮬레이션을 통해 각 경기의 승패 확률을 예측하는 웹 애플리케이션입니다.

기술 스택

구분 사용 기술
백엔드 Python 3.9, Flask, SQLAlchemy
데이터베이스 SQLite
시뮬레이션 NumPy (포아송 분포)
AI 분석 Anthropic Claude API (claude-sonnet-4-6)
데이터 수집 requests + 정규표현식 HTML 파싱
차트 Chart.js (득점 분포 시각화)

데이터 출처

공개된 두 사이트의 HTML을 직접 파싱합니다 (공식 API 미사용).

1. statiz.co.kr

수집 항목 상세
팀 순위표 순위, 경기 수, 승/무/패, 승률, 득점/실점
예정 경기 선발 투수 이름, 시즌 스탯 (ERA, WHIP, WAR, 탈삼진, 볼넷 등)
선발 H2H 해당 투수의 상대 팀 타선 통산 ERA·OOPS·WHIP
위험 타자 상대 선발투수를 상대로 강한 타자 목록 (OPS 기준)
팀 전력 비교 팀 타율, 팀 OPS, 팀 ERA, 선발/불펜 WAR, 최근 맞대결
완료 경기 점수, 승리·패전·세이브·홀드 투수

수집 항목 상세

두 사이트의 데이터는 팀명 기준으로 병합하여 DB에 저장됩니다.

선발 투수 이름 보완: statiz 예측 페이지는 당일 경기에 한해 투수 스탯을 노출합니다. 전날 발표된 예정 경기 선발 투수는 KBO 공식 API(T_PIT_P_NM / B_PIT_P_NM)를 우선 사용합니다.

DB 구조

TeamStat    — 팀 순위/스탯 스냅샷 (스크래핑 시각별 이력 보존)
TodayGame   — 예정 경기 + 선발 투수 + 통계 JSON
RecentGame  — 완료된 경기 결과 (점수, 투수 기록, 예측 대비 분석)
Prediction  — 사용자 저장 예측 + 실제 결과 대조

RecentGame에는 경기 결과 저장 시 자동으로 아래 필드가 추가됩니다.

필드 내용
predicted_winner 시뮬레이션 예측 승팀
sim_confidence 예측 확신도 (%) — shrinkage 적용 후 값
sim_json 예측 시점 핵심 시뮬레이션 데이터 (factors, λ, ERA, 상성 등)
result_analysis 예측 vs 실제 자동 분석 텍스트 (markdown)

시뮬레이션 방식

개요

포아송 분포 기반 몬테카를로 시뮬레이션 10,000회를 실행하여 각 팀의 기대 득점(λ)을 추정하고, 득점 분포에서 승패 확률을 도출합니다.

numpy.random.poisson(λ_away, 10_000)  →  원정 팀 득점 분포
numpy.random.poisson(λ_home, 10_000)  →  홈 팀 득점 분포

away_wins = Σ(원정득점 > 홈득점) + 동점 × 0.5
home_wins = Σ(홈득점 > 원정득점) + 동점 × 0.5

λ (기대 득점) 계산 방법

각 팀의 λ는 블렌딩된 경기당 득점(RPG)을 기준으로 여러 보정 계수를 곱해 산출합니다.

λ_away = RPG_away(블렌딩) × ERA계수 × K-BB/9계수 × 피로도계수
       × 최근흐름 × 원정전적계수 × 위험타자계수 × 맞대결계수
       × 파크팩터 × 홈불펜복합계수

λ_home = RPG_home(블렌딩) × ERA계수 × K-BB/9계수 × 피로도계수
       × 최근흐름 × 홈전적계수 × 위험타자계수 × 맞대결계수
       × 홈어드밴티지(1.01) × 파크팩터 × 원정불펜복합계수

λ는 최소 2.5, 최대 10.0으로 클램핑됩니다.

파크팩터는 두 λ에 동일하게 곱해 구장 특성을 반영합니다.
불펜복합계수는 상대 팀의 불펜WAR + 팀ERA를 교차 검증해 반영합니다.

각 계수 상세

0. RPG 블렌딩 (시즌 + 최근 폼)

단순 시즌 평균 대신, 최근 7경기 실제 득점을 가중 반영합니다.

RPG_블렌딩 = 시즌_RPG × 0.80 + 최근7경기_평균득점 × 0.20
  • 최근 경기 데이터가 4경기 미만이면 시즌 RPG만 사용 (이상값 방지)
  • 최근 RPG는 리그평균의 ±40% 이내로 클램핑 (단일 폭발 게임 영향 억제)

1. ERA 계수 (선발 투수 지배력)

상대 선발 투수의 ERA로 자 팀의 득점 기대값을 조정합니다.

ERA계수 = ERA / 리그평균ERA(4.50)
범위: [0.55, 1.75] 클램핑

시즌 ERA + H2H ERA 블렌딩:

H2H_가중치 = 0.35 (5경기 이상) / 0.25 (5경기 미만)
ERA계수(최종) = 시즌ERA계수 × (1 - H2H_가중치) + H2H_ERA계수 × H2H_가중치

2. K-BB/9 폼 계수 (투수 구위·제구 종합)

선발 투수의 K-BB/9 지표가 리그 평균(4.5)을 초과할수록 상대 득점을 억제합니다.

K-BB/9계수 = 1.0 - (K-BB/9 - 4.5) / 4.5 × 0.15
범위: [0.93, 1.07] 클램핑
  • K-BB/9 7.0 (지배적) → 계수 0.93 (상대 득점 7% 억제)
  • K-BB/9 2.0 (부진) → 계수 1.07 (상대 득점 7% 증가)

시뮬레이션 화면에서 K-BB/9 ≥ 3.0 이면 하이라이트 표시.

3. 피로도 계수 (최근 등판 간격)

선발 투수의 마지막 실전 등판(승/패 기록 기준) 이후 경과 일수로 체력 부담을 반영합니다.

2일 이내 등판 → 피로도계수 = 1.10 (상대 득점 10% 증가)
3일 이내 등판 → 피로도계수 = 1.05 (상대 득점 5% 증가)
4일 이상      → 피로도계수 = 1.00 (정상)

데이터가 없으면 1.0 처리. 시뮬레이션 페이지에 ⚠️ 배지로 표시됩니다.

4. 최근 흐름 (연속 기록)

흐름계수 = 1.0 + min(|연속수|, 5) × 0.015 × 방향(+1/-1)

예) 5연승 → 1.075 / 5연패 → 0.925

5. 홈/원정 전적 계수

홈전적계수 = 홈승률 / 0.500
원정전적계수 = 원정승률 / 0.500
범위: [0.75, 1.20] 클램핑

6. 위험 타자 OPS 계수

위험타자계수 = 1.0 + (평균OPS / 리그평균OPS(0.750) - 1.0) × 0.25
범위: [0.90, 1.15] 클램핑

7. 최근 맞대결 계수

맞대결계수 = (맞대결승수 / 총맞대결수) / 0.5
범위: [0.92, 1.08] 클램핑

8. 통산 상대팀 승률 계수 (상성)

상성계수 = 1.0 - (통산승률 - 0.5) × 0.20 × 샘플가중치
샘플가중치 = min(1.0, 통산경기수 / 15)
범위: [0.93, 1.07]

3경기 미만은 샘플 부족으로 무시.

9. 홈 어드밴티지

홈 팀 λ에 고정 계수 1.01 적용 (실측 데이터 기반 캘리브레이션으로 1.04에서 하향).

10. 파크팩터 (구장 특성)

홈팀 구장 파크팩터
LG / 두산 잠실 1.05
한화 대전 한화생명이글스파크 1.02
KIA 광주 챔피언스필드 1.01
롯데 부산 사직구장 1.00
삼성 대구 라이온즈파크 0.97
SSG 인천 SSG 랜더스필드 0.97
키움 서울 고척 스카이돔 0.96
NC 창원 NC파크 0.95
KT 수원 KT 위즈파크 0.93

파크팩터는 원정·홈 두 팀의 λ에 동일하게 적용됩니다.

11. 불펜 복합 계수 (WAR + 팀ERA 교차 검증)

단일 WAR 지표의 노이즈를 줄이기 위해 불펜WAR와 팀ERA를 가중 블렌딩합니다.

불펜WAR계수  = 1.0 - (불펜WAR - 리그평균(3.0)) / 3.0 × 0.25   → [0.92, 1.08]
팀ERA계수    = 1.0 + (팀ERA - 4.50) / 4.50 × 0.18              → [0.93, 1.07]

불펜복합계수 = 불펜WAR계수 × 0.60 + 팀ERA계수 × 0.40
  • 홈 팀 불펜 강함 → λ_away 감소 (홈 불펜이 원정 타선 억제)
  • 원정 팀 불펜 강함 → λ_home 감소

최종 승률 산출

몬테카를로 결과에 최근 10경기 흐름을 30% 블렌딩한 뒤, 과잉확신 억제(Shrinkage)를 적용합니다.

raw승률(원정) = 시뮬레이션승률 × 0.70 + 최근10경기승률 × 0.30

# Shrinkage: 극단적 확신도를 50%로 수렴 (계수 0.75)
최종승률(원정) = 50 + (raw승률 - 50) × 0.75
최종승률(홈)   = 100 - 최종승률(원정)

예) raw 80% → 최종 62.5% / raw 60% → 최종 57.5%

시뮬레이션 출력 (추가 지표)

득점 분포 차트 (Chart.js)

시뮬레이션 페이지와 완료 경기 상세 페이지에서 포아송 PMF 기반 득점 분포를 시각화합니다.

  • 0~15점 구간의 확률 히스토그램
  • 원정(파란색) / 홈(주황색) 겹쳐 표시
  • λ 값이 저장된 경기는 예측 당시 분포를 복원 가능

득점 범위 (25~75% 분위수)

p25, median, p75 = np.percentile(scores, [25, 50, 75])

선발 투수 제구·탈삼진 지표

지표 계산식 의미
K/9 탈삼진 / 이닝 × 9 9이닝당 탈삼진 수
BB/9 볼넷 / 이닝 × 9 9이닝당 볼넷 허용 수
K-BB/9 (탈삼진 - 볼넷) / 이닝 × 9 제구+구위 종합 지표

경기 결과 자동 분석 (Post-Game Analysis)

스크래핑으로 새 경기 결과가 들어올 때마다 예측 vs 실제를 자동 비교 분석합니다.

동작 흐름

admin/scrape 실행
  └─ 새 RecentGame 저장
       └─ TodayGame (선발 투수/스탯) + 경기 전 TeamStat 스냅샷으로 시뮬레이션 재현
            └─ 예측 승팀, 확신도, 핵심 데이터 저장
                 └─ 예측 정확도 분석 텍스트 생성 → result_analysis 저장

분석 생성 방식

ANTHROPIC_API_KEY 설정 시 Claude API로 서술형 분석 생성, 미설정 시 규칙 기반 fallback 자동 적용.

삼성 라이온즈 우선 표시

응원팀(삼성 라이온즈)의 경기를 모든 화면에서 우선 노출합니다.

  • 홈 화면: 최근 경기·다음 경기 카드에서 삼성 경기 맨 위
  • 순위표: 삼성 행 파란색(#074CA1) 테두리·배경 강조
  • 캘린더: 삼성 경기 파란색 테두리, 해당 월 삼성 경기 카드 하단 별도 요약
  • 통계: 팀별 적중률 테이블에서 삼성 행 강조

경기 상세 페이지 (/game/...)

완료된 경기를 클릭하면 KBO 공식 API에서 박스스코어를 실시간으로 가져와 표시합니다.

섹션 내용
경기 헤더 날짜, 구장, 최종 스코어, 승리·패전·세이브 투수
경기 특이사항 결승타, 홈런, 2루타 등 주요 장면
타자 성적 원정·홈 각각 — 타순, 포지션, 이닝별 타격, 타수/안타/타점/득점/타율
투수 성적 원정·홈 각각 — 이닝, 피안타, 탈삼진, 볼넷, 실점, 자책, 결과
득점 분포 차트 예측 시점 λ 기반 포아송 분포 복원 시각화
예측 결과 분석 적중·빗나감 원인 분석 (markdown 렌더링)

통계 페이지 (/stats)

섹션 내용
전체 요약 수동/시뮬레이션 예측 수, 적중 수, 적중률
신뢰도별 정확도 50~59% / 60~69% / 70~79% / 80%+ 구간별 실제 적중률
월별 추이 차트 시뮬레이션 적중률 월간 변화 (Chart.js)
팀별 예측 적중률 팀별 전체·홈·원정 예측 수 및 적중률 테이블
팀 상성 히트맵 10×10 매트릭스로 팀간 상대전적 승률 색상 표시

예측 캘린더 (/calendar)

월간 달력 형태로 경기 결과와 예측 적중 여부를 한눈에 확인합니다.

  • ✅ 적중 (초록 테두리) / ❌ 빗나감 (빨간 테두리) / 예측 없음 (회색)
  • 삼성 경기는 파란 테두리로 강조
  • 하단에 해당 월 삼성 라이온즈 경기 카드 별도 목록

실행 방법

# 의존성 설치
pip install -r requirements.txt

# 환경변수 설정 (AI 분석 사용 시)
export ANTHROPIC_API_KEY=sk-ant-...

# 앱 실행
python run.py

브라우저에서 http://localhost:5000 접속 후, 홈 화면의 데이터 갱신 버튼을 눌러 최신 데이터를 수집합니다.

정적 블로그 (GitHub Pages)

build_blog.py 를 실행하면 시뮬레이션 결과를 정적 HTML 블로그로 생성하고 GitHub Pages에 자동 배포합니다.

블로그 주소: https://namjinwoo.github.io/kbo/

블로그 탭 구성

탭 내용
오늘 경기 분석 날짜별 완료 경기 목록 → 경기 카드 (예측 적중 여부, 승률 바, 위협 타자, 분석 텍스트, 박스스코어)
다음 경기 예상 날짜별 예정 경기 목록 → 경기 카드 (선발 투수 ERA, 승률 바, 기대득점 λ, 위협 타자, 분석 텍스트)
소개 이 README 문서 전체를 블로그 내에서 렌더링

업데이트 방법

# Flask 앱에서 최신 데이터 스크래핑
curl -X POST http://localhost:5000/admin/scrape

# 블로그 빌드 및 배포
python build_blog.py

시뮬레이션 한계 및 유의사항

  • 부상, 날씨, 컨디션 등 비정형 변수는 반영되지 않습니다.
  • H2H 샘플 크기가 작을 경우 해당 계수의 신뢰도가 낮습니다.
  • 선발 투수 미정 경기는 ERA 계수를 1.0(리그 평균)으로 처리합니다.
  • RPG 블렌딩은 DB에 팀당 4경기 이상 데이터가 쌓여야 활성화됩니다.
  • 본 예측은 통계적 참고 자료이며, 투자·도박 목적으로 사용하지 마십시오.
